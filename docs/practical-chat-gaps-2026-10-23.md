# Практические ошибки последнего N1

Проверены новые сообщения «Испытание N1» в рабочей SQLite, открытой только
для чтения. Исходные заметки, история и выбор модели не менялись.
Результаты прежних коротких прогонов не покрывали эти сценарии.

## Наблюдения и изменения

| Реплика/цель | Наблюдавшееся поведение | Новое поведение |
|---|---|---|
| «Открой новый документ md» | Семантический выбор чужого файла | Сначала точное имя/основа, затем буквальный алиас с точкой; отсутствующее имя не подменяется |
| «не то открыл» | Ответ по посторонним заметкам | Журнал действия; повтор исходного буквального открытия при однозначном разрешении |
| Создать общий пересказ всего в директории, имя выбрать самостоятельно | Ненужное уточнение параметров | Типизированное создание до LLM-маршрутизации, свободное имя |
| Пересказать всю папку | Четыре найденных фрагмента, ошибочно названные составом директории | Список источников и отдельная обработка всех их частей |
| Содержимое создаваемого документа | Системой добавлялось «кратко», бюджет 192 токена; в файл попадала отметка об обрыве | Убрана принудительная краткость; отдельный авторский маршрут для всего корпуса |
| Жалоба на огрызок | Переписывание жалобы в команду открыть/прочитать файл | Восстановление исходной задачи и продолжение; проверенные разделы по неизменённым ревизиям сохраняются |

Автор возвращает предложения с ID буквальных доказательств. Независимый
аудитор использует прежние защиты субъекта, действия, модальности, говорящего,
адресата и примера. Неверно сформированное сравнение, где вместо участника
скопировано длинное предложение «В заметке …», отклоняется; пакет получает
существующий запасной путь отдельных проверок. Это не положительный вердикт.

При одном исправлении проверяются новые предложения. Частичный отказ не
стирает ранее подтверждённые. Список файлов и ревизии проверяются перед
сохранением. Незавершённый результат маркируется `PARTIAL` и содержит пропуски.
Новые версии не перезаписывают старые. Журнал документов доступен в обычном чате:
для каждой сверки можно раскрыть предложения, их вердикты и цитаты-доказательства.

## Контролируемые проверки

- Окончательный полный набор: **681/681**, 135,5 секунды. Профильный набор
  новых практических сценариев: **22/22**.
- Production frontend собирается. Браузерный прогон с отдельными настоящими

  пересказ шести отдельных документов и показ охвата/сверки в журнале.
  Сохраняются прежние проверки записи/backup, конвертации, предпросмотра,
  отмены, исправления кода после упавшего теста и журнала после reload.
- Автор и аудитор браузерного сценария контролируемые; это проверка
  интеграции, не доказательство качества локальной модели.

Приватные журналы: `.user-evaluation/practical-all-final.log`,
`practical-gaps-retained-final.log`, `practical-frontend-build.log`, `practical-browser-final.log`.

## Реальная локальная модель и весь корпус

Все 20 документов перенесены байтами в изолированную папку. Профиль BALANCED,
локальная Qwen 3.5 4B; библиотека/embeddings для этого маршрута не требуются.
Оригинальная база, документы и выбор модели проверяются по хешам, системное
открытие заменено наблюдателем. Подробные ответы и источники не публикуются.

Первый вариант с обычным бюджетом ответа сохранил честно неполный результат:
175,6 секунды, 13 подготовленных/проверенных частей, 4975 символов. Он не
прошёл критерий полного охвата. После выделения отдельного бюджета по частям
обработаны все 22 части, но независимая сверка оставила два документа с
замечаниями: 390,2 секунды, 8476 символов, `PARTIAL`. Этот прогон также не
объявлялся успешным.

Продолжение после перезапуска backend с восстановлением по журналу:
**20/20 документов**, **8995 символов**, **46,7 секунды**. Переиспользовано
18 проверенных разделов; выполнено три новых подготовки/сверки, включая
локальное исправление. Итог `COMPLETED`. Все защищённые хеши сохранились,
системного открытия не было, код не менялся во время прогона.

Артефакты продолжения:
`.user-evaluation/20261022-235912/practical-summary-resumed-report.json`
и `practical-summary-resumed-response.json`.

Отдельный повтор создания с нуля: **363,1 секунды**, все 22 части прочитаны и
проверены, но полный пересказ принят для **19/20 документов**. Сохранено 8929
символов с `PARTIAL`. В оставшемся предложении автор превратил прямо
отвергнутую источником категорию в положительное утверждение; независимая
сверка его не пропустила. Этот прогон не прошёл критерий полноты.
Артефакт: `.user-evaluation/20261023-101347/practical-summary-report.json`.

После этого улучшена подсказка локального исправления с сохранением отрицания
и продолжение внутри незавершённого файла: старое подтверждённое предложение
с действующей цитатой остаётся, исправляется только пробел с передачей прошлых
замечаний. Повтор готового предложения не закрывает этот пробел. Эти сценарии
покрыты отдельными проверками. Повтор полного создания с нуля после данной
последней правки не проводился; отдельно проверено продолжение именно этого результата.

Продолжение этого последнего результата на окончательном коде прошло:
**20/20 документов**, **9238 символов**, **35,7 секунды**, `COMPLETED`.
Переиспользовано 19 готовых разделов и два проверенных предложения внутри
оставшегося файла. Одна новая подготовка и независимая сверка с локальным
исправлением закрыли пропуск. Защищённые хеши сохранились, системного открытия
не было, код не менялся во время прогона. Артефакты:
`.user-evaluation/20261023-101347/practical-summary-resumed-report.json`
и `practical-summary-resumed-response.json`.

## Практические границы

Покрытие всех входных частей и независимая сверка не гарантируют, что пересказ
сохранил каждую важную деталь. Маленькая модель может ошибаться и отклонять
корректное предложение; это даёт явный неполный результат. Неизменённые разделы
переиспользуются только для продолжения сохранённой неполной задачи этого чата
и workspace с совпадающими ревизиями. Заявление о высокой скорости для любых
развёрнутых документов эти замеры не поддерживают: подготовка всего корпуса
занимает минуты, продолжение существенно дешевле.

Проверены исходники, изолированный backend и собранный web-интерфейс.
Установленный desktop sidecar/installer в этой задаче не пересобирался.
