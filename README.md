# Универсальная RAG-система для обработки текста с многоагентной архитектурой

Это веб-приложение использует подход Retrieval-Augmented Generation (RAG) для создания чат-бота на основе LangChain и FastAPI. Приложение позволяет загружать и индексировать документы для семантического поиска, улучшая ответы ИИ, включая интеграцию с Google Drive для обработки документов и многоагентную цепочку (draft/edit/enhance/merge) для итеративного улучшения текста.

## Возможности

- **Чат с ИИ:**  
  Ведите диалог с ИИ-ассистентом, который учитывает историю переписки и использует контекст из загруженных документов для точных ответов. Поддержка single RAG и multi-agent mode (цепочка агентов для качества).

- **Загрузка документов:**  
  Загружайте документы в форматах PDF, DOCX, HTML и TXT для индексирования и использования в ответах.  
  *Новое*: Поддержка OCR для сканов, drag-and-drop, ограничение 200 МБ.

- **Интеграция с Google Drive:**  
  *Новое*: Загрузка целых папок рекурсивно, OAuth2 auth, автоматическая обработка вложенных файлов.

- **Управление документами:**  
  Просматривайте список загруженных документов с ID, названием и датой; удаляйте ненужные.

- **Multi-Agent Mode:**  
  *Новое*: Итеративная цепочка (draft → edit → enhance с вариантами → merge) для креативной/структурированной обработки текста.

## Технологический стек

- **FastAPI:** Сервер для обработки API-запросов.
- **LangChain + LangGraph:** Управление RAG-цепочками и многоагентными workflows.
- **Chroma:** Векторное хранилище для семантического поиска по чанкам.
- **SQLite:** Локальная база данных для истории чата и метаданных документов.
- **Streamlit:** Веб-интерфейс для взаимодействия с пользователем.
- **Google Drive API:** Интеграция для загрузки документов с Google Drive.
- **Gemini 2.5 (Google Generative AI):** LLM для embeddings и генерации (flash/pro).
- **Unstructured + Pytesseract:** OCR для PDF-сканов.
- **Git:** Система контроля версий.

## Структура проекта

- **api_utils.py:** Функции для отправки HTTP-запросов к серверу (чат, загрузка, получение и удаление документов).
- **chat_interface.py:** Реализация чат-интерфейса на Streamlit.
- **sidebar.py:** Боковая панель для выбора модели, загрузки документов (локальных и с Google Drive) и управления ими.
- **streamlit_app.py:** Главный файл для запуска приложения Streamlit.
- **db_utils.py:** Работа с базой данных для хранения истории чата и метаданных документов.
- **chroma_utils.py:** Индексация документов в векторное хранилище Chroma с hybrid retriever.
- **langchain_utils.py:** Создание RAG-цепочек с использованием LangChain и Gemini.
- **multi_agent_chain.py:** *Новое*: Многоагентная цепочка на LangGraph (draft/edit/enhance/merge).
- **pydantic_models.py:** Модели Pydantic для валидации запросов и ответов.
- **hybrid_context_extractor.py:** Пользовательский гибридный ретривер для улучшенного извлечения контекста.
- **gdrive_auth.py:** Модуль аутентификации для Google Drive API.
- **gdrive_extractor.py:** Модуль для извлечения и обработки документов с Google Drive (рекурсивно, с OCR).
- **credentials.json:** Конфигурация OAuth 2.0 для Google Drive API.
- **token.json:** Хранение токенов доступа и обновления для Google Drive API.

## Требования

- Python 3.10 или выше.
- Учетные данные Google Drive API (см. раздел "Настройка Google Drive").
- Установленные зависимости из `requirements.txt`.

## Установка и запуск

1. **Клонируйте репозиторий:**

   ```bash:disable-run
   git clone <URL-репозитория>
   cd RAG_GoogleDisk_ScriptAssistant
   ```

2. **Установите зависимости:**

   ```bash
   pip install -r requirements.txt
   ```

3. **Настройка Google Drive API:**

   - Перейдите в [Google Cloud Console](https://console.cloud.google.com/).
   - Создайте проект и включите Google Drive API.
   - Создайте учетные данные OAuth 2.0 (выберите "Desktop app") и скачайте файл `credentials.json`.
   - Поместите `credentials.json` в корневую директорию проекта.
   - При первом запуске приложение запросит аутентификацию, создав файл `token.json`.

4. **Настройка .env:**

   ```
   GOOGLE_API_KEY=your_key_here
   ```

5. **Запустите сервер FastAPI:**

   ```bash
   cd api
   uvicorn main:app --reload
   ```

6. **Запустите приложение Streamlit:**

   ```bash
   cd app
   streamlit run streamlit_app.py
   ```

7. **Откройте приложение:**

   В браузере перейдите по адресу:

   ```bash
   http://localhost:8501
   ```

## Использование

- **Чат:** Вводите запросы в интерфейсе чата. ИИ будет отвечать, используя контекст из загруженных документов. Включите "Multi-Agent Mode" для итеративной цепочки (улучшенное качество).
- **Загрузка документов:** Используйте боковую панель для загрузки локальных файлов (PDF, DOCX, HTML, TXT) или укажите URL папки Google Drive для индексации нескольких документов (с OCR для сканов).
- **Управление документами:** Просматривайте и удаляйте загруженные документы через боковую панель.
- **Примеры запросов:** "Напиши сюжет на основе данных", "Анализируй отчёт из файла", "Улучши эссе с вариантами".

## Примечания

- Файлы `credentials.json` и `token.json` содержат чувствительные данные. Храните их в безопасности и не добавляйте в публичные репозитории.
- Поддерживаемые форматы документов: PDF, DOCX, HTML, TXT (с OCR для PDF-сканов).
- Для загрузки с Google Drive требуется действительный URL папки (например, `https://drive.google.com/drive/folders/<folder-id>`).
- Multi-Agent Mode может занять 30-90 сек (4 LLM-вызова); fallback на single RAG для скорости.
