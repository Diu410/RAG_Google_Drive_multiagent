# Задачи для репозиторного агента

Три проекта с намеренными ошибками: учёт оплаченных счетов на Python,
ограничение числового диапазона на JavaScript и расчёт заказа через два
Python-модуля с процентами и округлением. Они запускаются только на копиях
через `tests/benchmark_repository_agent.py`. Исходные примеры остаются ошибочными
для повторяемого сравнения. Независимые критерии находятся вне папок проектов.
