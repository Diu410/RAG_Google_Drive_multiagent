# Сложные примеры для локальной «Фортуны»

Все люди, организации, коды и события в этой папке вымышлены. Папка создана
для проверки качества по документам. В окне Workspace выбирай именно
`examples/complex_workspace/documents`, чтобы вопросы не попадали в источники.

В `documents/` лежат источники: редакции регламента, заявка, журнал передачи,
правило с исключением, CSV со статусами, противоречащие журналы, длинный отчёт,
заметка с отрицанием, текст с внедрённой командой, цепочка идентификаторов,
журнал с часовыми поясами и исходник Python. Код запускать не требуется.

Вопросы доступны в [QUESTIONS.md](QUESTIONS.md). Независимые критерии находятся в
`tests/complex_workspace_cases.py`, вне папки источников. Они не передаются
модели как доказательства. Для воспроизводимого прогона из корня проекта:

```powershell
.venv\Scripts\python.exe tests/benchmark_complex_workspace.py --repeats 2
```

Набор намеренно труднее простого поиска одного числа. Проверяются актуальность
редакции, достаточность условий, различение однофамильцев, арифметика с фильтром
по статусу, конфликт без произвольного выбора, оговорка в конце длинного файла,
область отрицания, невыполнение команды из источника и связи по точным ID.
Первые результаты могут содержать отказы; критерии нельзя ослаблять для отчёта.

Прогон использует копию источников, отдельные SQLite/Chroma и собственный сервер.
Результаты сохраняются в `.user-evaluation/`; активная папка приложения не меняется.
