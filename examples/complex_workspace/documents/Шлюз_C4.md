# Шлюз C-4: условия открытия и проверяемый сеанс

Обычное открытие шлюза C-4 разрешено, только если одновременно выполнены оба
условия: давление не выше 0,6 МПа и флаг R включён.
Отсутствующий флаг R не считается включённым.

Исключение для аварии: при выключенном R открыть шлюз может только дежурный
офицер безопасности, и только при давлении не выше 0,3 МПа.
Запрос начальника смены сам по себе не является разрешением офицера безопасности.

В сеансе S-41 давление равно 4 барам, то есть 0,4 МПа; флаг R выключен.
Начальник смены запросил аварийное открытие. Офицер безопасности разрешение
не выдавал и шлюз не открывал.
