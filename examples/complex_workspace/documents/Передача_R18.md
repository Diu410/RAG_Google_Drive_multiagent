# Передача схемы узла R-18

В журнале участвуют два разных человека с одинаковым именем Анна Петрова.
Инженер Анна Петрова имеет ID A-17. Дизайнер Анна Петрова имеет ID P-22.
Эти ID не являются псевдонимами одного человека.

17 мая инженер A-17 отправила схему узла R-18 Олегу Смирнову, ID B-04.
Олег получил схему, но не является её отправителем.
Подписать окончательный макет должна дизайнер P-22. Подписи пока нет.
Отправка схемы инженером не подтверждает подписание макета дизайнером.
